한개국어 개인정보처리방침

시행일: 2026-11-09

수집하는 정보

  • 익명 사용자 ID: 앱을 처음 열면 이름·이메일 없이 익명 계정이 만들어집니다.
  • 학습 기록: 푼 문제와 정오답, 저장한 단어, 모은 보물.
  • 검색어: 단어 검색과 '뜻으로 단어 찾기'에 입력한 글.

가입을 위해 이름·이메일·전화번호를 요구하지 않으며, 위치·연락처·사진 접근 권한을 요청하지 않습니다. 다만 직접 입력하는 검색 설명이나 문의 이메일에 개인정보가 포함될 수 있으므로, 단어 설명에 불필요한 개인정보를 입력하지 마세요.

이용 목적

  • 학습 기록과 저장 단어를 보여 주는 앱 기능 제공.
  • '뜻으로 단어 찾기'는 입력한 설명을 Anthropic의 AI 모델(Claude)에 보내 후보 단어를 받습니다. 이 처리에는 외부 AI 서비스가 사용됩니다.

보관과 처리

  • 데이터는 Supabase(서울 리전)에 저장됩니다.
  • 광고·추적에 쓰지 않고 제3자에게 판매하지 않습니다.
  • 단어 검색 통계는 사용자와 연결하지 않고 날짜·단어별 횟수로만 집계합니다.

계정 및 학습 데이터 삭제

삭제 기능이 포함된 앱에서는 학습 또는 기록 화면의 설정(톱니바퀴)을 누른 뒤, ‘계정 및 학습 데이터 삭제’ → ‘영구 삭제’를 선택하세요. 확인 화면에서 취소할 수 있습니다.

  • 삭제를 확정하면 서버의 익명 계정과 연결된 답안·학습 기록·저장 단어·보물 데이터, 기기에 저장된 학습 데이터와 최근 검색어를 삭제합니다. 삭제한 데이터는 복구할 수 없습니다.
  • 삭제 후 계정을 자동으로 다시 만들지 않습니다. 사용자가 다시 시작하기를 선택하면 새 익명 계정이 생성됩니다.
  • 삭제 처리의 재시도 확인을 위해 계정 연결이 제거된 요청 번호와 처리 상태가 남을 수 있습니다. 사용자와 연결하지 않는 날짜·단어별 검색 집계는 유지됩니다.
  • 앱 삭제만으로 서버 계정이 삭제되지는 않습니다. 삭제 메뉴가 없거나 앱에 접근할 수 없으면 remin1994@gmail.com으로 ‘한개국어 계정 삭제 요청’을 보내 주세요. 익명 계정을 확인하기 위한 안내를 드립니다. 비밀번호나 인증 토큰은 보내지 마세요.
